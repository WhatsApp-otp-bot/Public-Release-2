🛡️ Key Repository Features

  • Programmatic Phishing Detection: Python module for validating incoming WhatsApp verification URLs and blocking typosquatting domains.
  • Cryptographic Flow Analysis: Step-by-step architectural breakdown of SMS gateway handshakes and secure session generation.
  • Operational Security Audits: Complete checklists for two-step verification (2FA) and carrier voicemail hardening.
